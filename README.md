# TP4 - Gestion des données avec JavaScript

## Description
Application web de gestion des données avec JavaScript et des fichiers JSON.

## Structure du projet
- index.html : page principale
- css/style.css : mise en forme
- data/ : fichiers JSON
- js/ : scripts JavaScript

## Fonctionnalités
- Chargement des données JSON
- Relations entre les données
- Affichage dynamique
- Filtrage des données

## Exécution
Ouvrir le projet dans Visual Studio Code et lancer index.html avec Live Server.
